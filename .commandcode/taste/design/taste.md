# Design

- Wants UI built from the existing design system rather than per-screen bespoke styles: reuse the established theme tokens (typography, colors, spacing, borders, field heights, icons, button styles) and shared/reusable components so every screen — forms, reports, lists, dialogs, states — looks consistent. Confidence: 0.6
- For icon assets, wants minimal, clean, flat vector icons on a 24×24 viewBox with a transparent background, stripped of unnecessary detail so they stay legible at small sizes, using only simple colors that match the app's modern theme. Confidence: 0.55
- Wants default/stock framework glyphs (e.g. plain Material icons) swapped out for custom-drawn "modern" icons across navigation surfaces, rather than left as the library defaults. Confidence: 0.55
- Prefers dark mode for the app's visuals — states it "looks better" — and wants a single theme applied consistently across a final set of screenshots rather than mixing light and dark. Confidence: 0.6
